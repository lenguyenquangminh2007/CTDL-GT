Bài toán tổng 4 phần tử: Cho một mảng số nguyên chưa được sắp xếp, hãy kiểm tra xem nó có chứa bộ bốn phần tử (bộ tứ) có tổng cho trước hay không.
Đầu vào: nums = [ 2, 7, 4, 0, 9, 5, 1, 3 ]
target = 20 
Đầu ra: Bộ bốn số tồn tại. Dưới đây là các bộ bốn số có tổng bằng 20 : (0, 4, 7, 9)(1, 3, 7, 9)(2, 4, 5, 9)
